Root cause — the adversary never learned

The failure signature is diagnostic and rules out the ROADMAP's first-suggested fix.

  • Worst-of-both-worlds: syllable F1 dropped 0.13 and cage stayed perfectly decodable (probe = 1.00). A too-aggressive λ would push the cage probe down (encoder over-erasing); instead the cage was fully retained — so the adversary didn't over-work, it didn't work at all.
  • Smoking gun: domain_loss sat flat at ~1.39 the entire run and never declined — ≈ chance for the 2-cage discriminator. The in-loop domain head never learned to separate lab from vocalmat even though the features are perfectly separable (the post-hoc linear probe nails them at 1.00, and the VAE re-run shows knn 0.98 / PC1 d=1.87 / per-dim d=3.31).
  • Implication: an adversary stuck at chance sends the encoder no useful gradient, so cage info is never removed; the F1 loss is collateral perturbation from the noisy domain term at lr=1e-3. Therefore slower ramp / lower γ (ROADMAP's levers) would make an already-ineffective adversary weaker — wrong direction. The real lever is getting the domain head to actually train (its own optimizer / LR, domain-loss weight, per-batch domain balance).

How we got the data onto the rig (the link saga)

The source domain (VocalMat, 633 MB) + manifests + domain_unlabeled.csv were already on the rig; only the 17 GB / 225K lab target patches were missing.

  • box→rig link is ~0.5–0.74 MB/s (Tailscale relay; a restart didn't establish a direct path — NAT traversal failed). Full push would have been ~6.6 hr.
  • Decision (user): subsample the DANN target to 20,000 lab patches (seed=42, all 83 lab recordings represented) — ~1.5 GB, ~34 min. Defensible: the script supports --max-target-samples, and 20K richly characterizes the lab cage vs the ~12K VocalMat source. The probe=1.00 failure is not a sample-size artifact.
  • GPU contention: the rig's 4× 3060 Ti were saturated by docker llama-server containers (root-owned; a bare kill respawned them). Freed GPUs 2 & 3 via docker stop llama-large (worked as shachar, no sudo). Left the user's contour-VAE (GPU 0, detached) and the embedding service untouched. Trained on GPU 2.
  • Warm-start verified faithful: v1→ResNet18DANN reproduced VocalMat val F1 = 0.7693 exactly (no head-mapping bug).
