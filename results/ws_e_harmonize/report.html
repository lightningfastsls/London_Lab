WS-E — Confound-Robust Cohort Comparison

ComBat / neuroHarmonize (cage removal) + CORAL cross-check; optimal transport (Wasserstein-2) and RBF-kernel MMD distance; four validation controls. Total calls: 47026. RBF γ=0.0354. Runtime 305s.

Headline (Gate E): 0 of 136 within-lab partner pairs differ with perm p<0.05 AND exceed the cross-cage noise floor (W2 = 1.992).
Core epistemic result: the batch axis is cohort, and for the wild groups cohort == cage == biological-unit. Removing the cage therefore removes the entire lab-vs-wild and wild-vs-wild signal — those contrasts are UNIDENTIFIABLE. The only environment with within-cage biological variation is the lab partner-swap matrix (17 pairings, constant cage), where ComBat applies a single shared affine map and leaves partner structure intact. That is where Gate E lives.

Method parameters

  • Batch/cage variable: cohort (4 levels). Lab = one cage / 17 partner pairings; 3 wild cages.
  • Features: 8 elastic-FPCA shape coords (5 amp + 3 phase), standardized to pooled unit variance for distances.
  • OT: exact ot.emd2, squared-euclidean ground; subsample 1500/group × 20 repeats.
  • MMD: unbiased RBF U-statistic, γ = median heuristic = 0.0354.
  • Permutation p: add-one estimator, 300 permutations, 600/group subsample.
  • Classifier: 5-fold stratified logistic regression, balanced accuracy. Chance: cohort 0.25, partner 0.059.
  • ComBat: neuroHarmonize, no biological covariate protected (pure batch removal). CORAL = second-order alignment cross-check.
  • Deviation: MMD uses an RBF kernel on FPCA coords, not GAK — GAK is for raw variable-length sequences; the WS-A elastic-FPCA coords already encode SRVF warp-aligned shape, so a sequence kernel is inapplicable. Documented and justified.
