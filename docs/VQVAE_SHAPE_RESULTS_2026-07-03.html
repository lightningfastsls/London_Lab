Does a VQ-VAE fix USV shape clustering? Partly — a real refinement, not a breakthrough

Direct test of Mickey's hypothesis · 2026-07-03 · global-code VQ-VAE on the registered ridge, scored on the standing human-anchored harness

One-paragraph result

Trained on the correct substrate (the 1-D registered ridge), a global-code VQ-VAE reaches the registration tier: shape η² = 0.572 at K=20, essentially tying registration's 0.577 and decisively beating every prior learned method — including the continuous 1-D VAE on the identical ridge (0.42–0.50) and the 2-D image-VAE (0.009). So Mickey is right that vector quantization helps relative to a plain VAE. But it does not beat the current production frontier (soft-DTW / elastic-FPCA), and on the human-anchored purity that measures alignment with perceived shape families it stays in the graded-continuum regime (NMI ≈ 0.18). The discrete codebook recovered what the continuous VAE was smearing away — but it did not turn the continuum into separable classes.

What was run

  • Model: global-code VQ-VAE — encoder → single latent vector → snap to nearest of K codebook entries (EMA updates, dead-code reset, straight-through) → decoder. One code per call, so the code index is the cluster. Code: scripts/experiments/vqvae_shape/.
  • Substrate: the registered 50-point ridge (data/shape_substrate/true_registered_ridges.npz, 67,337 calls) — pitch subtracted, active span resampled, i.e. the representation prior work identified as where shape actually lives.
  • Two configs: K=20 (matches the incumbent alphabet, apples-to-apples) and K=64 (matches the usv_language codebook default).
  • Codebook health: both healthy — K=20 stabilized at perplexity 14.8/20, K=64 at 41.4/64, 0 dead codes. No collapse, so results reflect the geometry, not a degenerate codebook.
  • Scoring: the project's own eval_shape_human_anchored.py functions (same join, same bootstrap purity) + the verbatim bake-off η² formula. Identical ruler to registration / soft-DTW / elastic-FPCA.

How to read it — three honest points

1. The quantizer genuinely helped vs a plain VAE. On the identical ridge substrate, the continuous 1-D VAE (M8) reached η² 0.42–0.50; the VQ version reached 0.572. The discrete bottleneck stopped the continuous latent from smearing cluster structure (the Gaussian/KL prior spreads mass between clusters; the codebook forces commitment). This is the specific sense in which Mickey's mechanism is correct, and it's a clean, reportable finding.
2. But it only reaches registration — it didn't find anything new. Registration's η² = 0.577 is plain KMeans-20 on the ridges. VQ-VAE at 0.572 is statistically indistinguishable from it, i.e. the learned codebook partitions ridge-space about as well as KMeans and no better. η² also rises with K by construction, so K=64's 0.674 is not a like-for-like win over K=20 registration — the fair comparison is K=20 VQ (0.572) ≈ K=20 registration (0.577). On the human-anchored purities, every apparent "win" (jump, chevron) has overlapping CIs with registration — none clears the non-overlapping bar the project uses for decisions.
3. It does not beat the production frontier, nor manufacture discrete classes. Soft-DTW still leads on jump (0.522 vs 0.482) and complex (0.243 vs 0.196) — the warp-aware metric remains the frontier. And NMI ≈ 0.18–0.23 means the codes align only weakly with human shape families: a code is still largely a pitch/duration/rough-arc bin. The continuum did not become separable kinds. The one flicker of class-like structure — K=64 chevron one-hot purity 0.305 (∼4× base rate) — is on n=44 (mostly Reverse Chevron) with a CI that touches registration, so it's a lead to probe, not a result.

Verdict on the hypothesis

Mickey was half right, in a precise and useful way. Vector quantization is a better bottleneck than a plain VAE for this problem — but only once you put it on the substrate that carries shape (the registered ridge), and even then it tops out at the registration/KMeans tier rather than discovering new categories. The result strengthens, rather than overturns, the standing conclusion: USV shape is a graded continuum, warp-alignment is the real lever, and no bottleneck yet turns it into crisp classes. What we gained is a clean positive data point — "a discrete codebook recovers the cluster-variance continuous VAEs lose" — and a small chevron-concentration lead worth chasing.

Still open — the literal test
