## Sanity-patch human review (the CHECKPOINT)

Browse `data/lab_cnn_training/sanity_patches/` in WSL Explorer (preferred) or VS Code's image preview. **This is the human-in-the-loop gate before Module 18.3 starts.** PLAN risk explicitly called out: `--subtract-baseline` may interact badly with VocalMat conventions. Look for:

- VocalMat patches: should match the original PNGs (script copies them verbatim). Spot-check a few against `data/vocalmat_full/<class>/*.png`.
- Lab patches (cohort=lab): should show clean USV traces at ~30-110 kHz, NO horizontal cage-tone lines at 50.4-51.0 kHz (soft-notch should have removed them, but it's a no-op without a tonal library — currently we have no calibrated library for the wild cohorts, only `lab_131204`).
- Wild patches: similar but without the lab 50 kHz cage line. The 5970 cage has its own acoustic signature.

If the patches look wrong (inverted contrast, USVs eliminated, lots of horizontal lines), STOP. Iterate on the cleaning stack BEFORE starting 18.3.

When patches look right, append a dated entry to `IMPLEMENTATION_PROGRESS.md` confirming the verdict + actual class counts. Then 18.2b is fully closed and 18.3 unlocks.
