The one job

A prior session implemented 2DPCA / (2D)²PCA (src/usv_spectrogram/classifier/twodpca.py) and benchmarked it against the production ResNet-18 on the 12-class VocalMat USV corpus. The classical method scored far below the CNN (best 0.240 vs 0.767). This task was not to improve the score — it was to break the conclusion: rule out that the low score is a bug in the library or driver. A correct implementation that still scores 0.24 is the success outcome, and that is what we found.

5. Bugs found — none material

The 46 pre-existing tests were treated as spec and left untouched. Four adversarial tests were added (tests/classifier/test_twodpca.py :: TestAdversarialMathCorrectness) and all pass:

  • NN vectorization == brute force — the vectorized sqrt(((Tr−te)²).sum(1)).sum(1) equals a naive double-loop over feature_matrix_distance (identical argmin predictions).
  • Non-square (64×48) projection orientation — the decisive guard. With square 64×64 a transposed projection A·Xᵀ would silently produce correct-shaped output; on 64×48 it raises, and project() returns A·X on the right axis. Olivetti alone cannot catch this; this test can.
  • Eigen-order / energy — eigenvalues strictly descending, ≥0; energy_ratio ∈ (0,1]; eigh matches eig to 1e-8.
  • Mean convention — train and test projected with the same convention (no train-only centering the test path skips).

One nuance (not a bug, reported for completeness): the recording-grouped split allocates recordings to train/val/test independently per class (dataset.py:build_stratified_split), so the global source_recording sets are non-disjoint (44–48 shared pairwise). This is a mild cage-acoustic leakage that can only inflate a score — so a still-low 0.24 makes the genuine-ceiling verdict stronger, not weaker. The split is out of scope for this task and was left untouched.

6. Verdict

CONFIRMED — implementation correct, ~0.24 is the genuine linear-method ceiling. No revision to the original negative result is warranted.

Why this conclusion is robust — three independent lines converge

  • Magnitude is right — Olivetti reproduces the published benchmark (LDA 0.915; NN 0.895 explained by the 64×64 dataset).
  • Axis is right — the non-square orientation test proves the projection uses the correct time/column axis (the square-image transpose trap is closed).
  • Ceiling is the data — flattened PCA independently hits 0.258, more components don't help (d=20→0.241), native resolution doesn't help (227→0.2405), and shuffling collapses to chance (0.065).

Methods & artifacts

  • Frozen recording-grouped split (seed 1729), 12-class VocalMat corpus, locked STFT render (not re-rendered).
  • Driver extension: a single additive --n-components / --n-components-row flag (default None → energy-based; backward-compatible). No production / canary files touched.
  • Memory-safe 227 run: scripts/experiments/resize227_bestconfig_2dpca.py accumulates the (2D)²PCA covariances in 500-image chunks (peak ~200 MB vs the library's ~10 GB float64 double-copy, which OOM'd an 11 GB box). Validated to reproduce the library's 0.2402 exactly at resize 64.
  • Scripts written: verify_2dpca_olivetti.py, pca_parity_2dpca.py, leakage_controls_2dpca.py, classweight_ablation_2dpca.py, resize227_bestconfig_2dpca.py (all under scripts/experiments/).
