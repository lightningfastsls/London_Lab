## Pending Task 1 — Down-sample test of UMAP unimodality

### Why
Phase 2B finding #2 says lab USVs cluster into one continuous mode regardless of HDBSCAN parameters, while wild-mouse 3452 produces 5+ separable clusters with the same defaults. This is **a new scientific claim**, but it confounds two variables: lab-vs-wild biology AND dataset size (40,787 lab vs 7,921 wild). A down-sample test isolates the biology.

### Plan
1. Sub-sample `classified_detections_lab_131204_clean.csv` to **n=7,921** (matching 3452 dataset size). Use stratified sampling on `couple` to preserve cohort distribution.
2. Re-run `recluster_umap_hdbscan.py` on the sub-sample with the **default params** (`--min-cluster-size 50 --min-samples 10`) — same params that produced 5+ clusters on 3452.
3. **If still 1 mega-cluster** → unimodality is dataset-independent → strong "lab USVs are less differentiated" finding. Report to Mickey.
4. **If multiple separable clusters appear** → unimodality was a dataset-size artifact at 40k. Walk back the finding in the Mickey report.

### Suggested implementation

```bash
cd /home/shachar/projects/mickey_london_lab

# 1. Stratified down-sample to n=7921
PYTHONPATH=. .venv/bin/python -c "
import pandas as pd
df = pd.read_csv('classified_detections_lab_131204_clean.csv')
target_n = 7921
# Stratified by couple, proportional
ds = df.groupby('couple', group_keys=False, observed=True).apply(
    lambda g: g.sample(n=max(1, round(len(g) * target_n / len(df))), random_state=42)
)
# Trim to exact target if rounding overshot
ds = ds.sample(n=target_n, random_state=42) if len(ds) >= target_n else ds
ds.to_csv('classified_detections_lab_131204_downsampled_n7921.csv', index=False)
print(f'wrote {len(ds)} rows')
"

# 2. Re-run UMAP+HDBSCAN with default params (matching 3452 conditions)
PYTHONPATH=. .venv/bin/python scripts/recluster_umap_hdbscan.py \
    --csv classified_detections_lab_131204_downsampled_n7921.csv \
    --output-dir results/recluster_umap_hdbscan_lab_131204_downsampled \
    --min-cluster-size 50 \
    --min-samples 10 \
    --skip-gallery

# 3. Inspect cluster_summary.csv — if cluster count == 3 with one mega-cluster, finding is robust
cat results/recluster_umap_hdbscan_lab_131204_downsampled/cluster_summary.csv
```

### Gate
- **3 or fewer clusters with one >70% mega**: unimodality robust → keep finding #2 in Mickey report
- **5+ clusters with no single >50% mega**: unimodality was dataset-size artifact → demote finding #2 to "needs investigation"
