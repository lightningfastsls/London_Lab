## Training command

Production 50-epoch run on a GPU host:

```bash
.venv/bin/python scripts/train_lab_classifier.py \
    --train-csv  data/lab_cnn_training/train/manifest.csv \
    --val-csv    data/lab_cnn_training/val/manifest.csv \
    --test-csv   data/lab_cnn_training/test/manifest.csv \
    --held-out-845 classified_detections_lab_131204_clean.csv \
    --output-dir results/lab_classifier_v1/ \
    --epochs 50 \
    --batch-size 64 \
    --lr 1e-3 \
    --warmup-epochs 3 \
    --focal-gamma 2.0 \
    --device cuda \
    --num-workers 4
```

**Note on `--warmup-epochs`:** the argparse default is 0 (so short
smoke/CI runs don't trip the validator); production runs MUST pass
`--warmup-epochs 3` explicitly — the cosine LR schedule depends on it.

Expected wall-clock time on a single consumer GPU (e.g., RTX 3060 or
better): ~30–90 min for 50 epochs over 9,741 patches at batch 64.
Larger batch sizes are fine if VRAM permits (the model is ~11 M params).

*label-distribution* statistics from the CSV alone. For Stream V the
real evaluation must additionally **load patches matching each held-out
CSV row and run the trained model**. This is the one piece of code that
must be written for Stream V — everything else is already in place.

### Minimal change required

  aren't available (so the existing smoke + adversarial tests still pass).

Add corresponding tests in `tests/classifier/test_training.py` (or a new
`test_held_out_real_inference.py`) — synthetic patches with known
labels, verify the eval function loads them correctly. **DO NOT modify

add new tests for the new code path.
