## Root-cause hypothesis (evidence-backed)

`domain_loss` was **flat at ~1.39 (≈ chance) for the entire run** and never declined,
yet the encoder features are **perfectly cage-separable** (post-hoc linear probe = 1.00;
VAE per-dim Cohen's d = 3.31). So **the in-loop domain head never learned** — it got no
traction on a signal that is trivially separable. An adversary stuck at chance sends the
encoder *no useful reverse gradient*, so cage info is never removed (probe 1.0), while the
noisy domain term at `lr=1e-3` still perturbs the warm-started encoder enough to drop
syllable F1 by 0.13. **This is an ineffective adversary, NOT an over-aggressive one** —
so the ROADMAP's "slower ramp / lower γ" would make it worse.

## Analysis — where to look (read first, don't re-run blind)

Inspect the adversarial loop in `scripts/train_lab_classifier_v2.py` (≈ lines 240–330, the
`_train_dann` / epoch loop). Check, in order:

1. **Does the domain head receive a NORMAL (un-reversed) gradient?** The GRL must reverse
   the gradient flowing to the *encoder* only; the domain head itself must minimize
   `domain_loss` normally. If λ or the reversal is mistakenly applied to the domain head's
   own parameter updates, it can never learn. (Unit tests cover GRL math on toy tensors but
   NOT the loop's optimizer wiring.)
2. **Per-batch domain balance.** If a step ever sees source-only or target-only patches, the
   2-class domain CE is uninformative. Confirm each adversarial step pairs source + target.
3. **Single shared optimizer at `lr=1e-3`.** The 2-layer domain head (Dropout 0.5) may be
   under-stepped relative to a moving encoder. Try a **separate optimizer / higher LR for the
   domain head**, or a domain-loss weight, so it can reach the separability the probe proves
   exists.
4. **Sanity probe:** before adversarial training, freeze the warm-started encoder and train
   ONLY the domain head a few epochs — it should reach ~1.0 (matching the post-hoc probe). If
   it can't, the wiring (1/2) is the bug. If it can, the loop's optimization cadence (3) is.
