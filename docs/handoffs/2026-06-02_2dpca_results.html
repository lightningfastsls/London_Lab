1. What is 2DPCA, and why does it suit spectrograms?

Classic PCA treats every image as a single long vector. A spectrogram patch that is m frequency bins tall and n time columns wide gets flattened into a vector of length m×n. PCA then needs the covariance of that vector — an (m·n) × (m·n) matrix. For even a modest 64×64 patch that is a 4096 × 4096 covariance (≈16.8 million entries), which is both slow to eigendecompose and badly under-determined when you have only a few thousand training images.

2DPCA (Yang et al., 2004) refuses to flatten. It keeps each image as a matrix A and builds a tiny column covariance by summing CᵀC over the centered images — an n×n matrix (here just 64×64 = 4096 entries, ≈4000× smaller than flattened PCA). Its leading eigenvectors form a projection that compresses the time axis while leaving the frequency axis intact. Each image becomes a slim feature matrix rather than a vector.

This structure is a natural fit for spectrograms specifically because the two axes are not interchangeable: rows are frequency, columns are time. 2DPCA lets you treat those axes asymmetrically. (2D)²PCA goes one step further and learns a second projection on the row (frequency) side using the CCᵀ covariance, squeezing the matrix on both sides at once — turning a 64×64 image into, for example, a 10×9 = 90-number feature with no giant covariance ever materialised.

2. The frozen algorithm (as implemented)

Source: src/usv_spectrogram/classifier/twodpca.py — pure NumPy, covariances via np.einsum, eigendecomposition via np.linalg.eigh.

2DPCA — one-sided (column) projection

# M training images Aᵢ (m×n), mean image Ā, centered Cᵢ = Aᵢ − Ā
Gt = (1/M) · Σᵢ Cᵢᵀ Cᵢ # n×n column covariance (symmetrized)
Gt = (Gt + Gtᵀ) / 2
eig(Gt) → eigenvalues λ (clipped ≥0, sorted desc), eigenvectors
d = smallest k s.t. (Σ₁..k λ) / (Σ λ) ≥ energy # default energy = 0.95
X = top-d eigenvectors # n×d projection
Y = (A − Ā) · X # feature matrix, m×d

(2D)²PCA — bilateral (column + row) projection

Gt' = (1/M) · Σᵢ Cᵢ Cᵢᵀ # m×m row covariance (symmetrized)
eig(Gt') → Z = top-q eigenvectors # m×q row projection
Y = Zᵀ · (A − Ā) · X # bilateral feature, q×d

Matrix distance & the 1-NN classifier

feature_matrix_distance(Yᵢ, Yⱼ) = Σcols ‖ Yᵢ[:,c] − Yⱼ[:,c] ‖₂
# "nn" = nearest feature matrix (vectorized over stacked train features):
dist = sqrt( ((Train − test)²).sum(axis=1) ).sum(axis=1) # argmin → predicted label

The "svm" / "lda" classifiers instead flatten the feature matrix, apply a StandardScaler, then fit a LinearSVC / LinearDiscriminantAnalysis.

6. Interpretation & limitations

  • Linear subspace vs deep nonlinear features. 2DPCA/(2D)²PCA are unsupervised, linear projections — they find directions of maximum pixel variance, not directions that separate syllable classes. A spectrogram's discriminative cues (curvature of a chevron, the step in a step-up) are nonlinear and spatially local; a global linear basis cannot represent them. ResNet-18 learns hierarchical nonlinear filters end-to-end against the labels, which is exactly why it triples the macro-F1. This is an expected, not a surprising, outcome — the study quantifies how large the gap is, not whether one exists.
  • 64×64 downscale. Every image was resized to 64×64 to keep the covariances tiny and the fit fast. That throws away fine time–frequency detail that distinguishes adjacent shape classes (e.g. the second step in a two-step). The CNN consumed its native higher-resolution input. Some of the 2DPCA gap is attributable to this aggressive downscale, though raising resolution would not close a 0.53 gap.
  • Severe class imbalance, especially on the rare tail. The test set has 135 Noise images but only 13 Reverse-Chevron and 7 Multi-steps. Macro-F1 weights every class equally, so the 0/0 on Multi-steps and 0.057 recall on Two-steps drag the average down hard. 2DPCA has no class-reweighting; ResNet-18 v1 used inverse-frequency class weights, which is part of why it holds up on the tail. A like-for-like comparison would add resampling or class weighting to the LDA head — but even generously, the linear ceiling is far below the CNN.
  • What the numbers do and don't say. All four configs beat the 0.083 chance floor and none collapsed into a single predicted class (0/12 rows >0.9-dominated), so the method is extracting real signal — just not enough. The result is a clean negative: the classical 2DPCA family is not a candidate to replace or cheaply approximate the production ResNet-18 classifier on this corpus.
