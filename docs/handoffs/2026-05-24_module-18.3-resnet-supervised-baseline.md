## Goal

Train a 12-class syllable classifier (Grimsley 2011 taxonomy) using `timm`'s ResNet-18 ImageNet-pretrained backbone, with class-weighted focal loss + SpecAugment + cage-noise injection, on the VocalMat-curated supervised manifest produced by Module 18.2b. Evaluate on the test split + the held-out 845 lab 131204 dual-rater verdict set. In parallel (D3 sidequest, ~1 day), train a Perch 2.0 frozen-embedding linear probe and compare.
