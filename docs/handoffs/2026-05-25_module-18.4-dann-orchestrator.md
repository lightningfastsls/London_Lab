## TL;DR of the work

Train a DANN variant of the 18.3 classifier so the supervised head still predicts the 12 Grimsley classes from VocalMat (labeled, source domain) while a gradient-reversal-layer (GRL) classifier head learns to confuse lab vs wild patches (unlabeled, target domain). Goal: a feature representation that generalizes from VocalMat to the lab domain *without* requiring lab-labeled training data.

Then evaluate on the **re-extracted 844-row lab held-out set** (which was deferred from 18.3 — see "Tier-2 prerequisite" below).

## What the DANN code needs to add

A new module `src/usv_spectrogram/classifier/dann.py` with:

- `GradientReversalLayer` (the canonical `torch.autograd.Function` with forward = identity, backward = `-lambda * grad`).
- `DomainClassifier` head (2-class: source/target) attached to the same feature trunk as the existing 12-class classifier.
- A `train_dann` loop that:
  - Loads source batches from the VocalMat train manifest (labels = Grimsley class).
  - Loads target batches from `domain_unlabeled.csv` (labels = source vs target, NOT Grimsley class).
  - Computes a combined loss: `L_cls(source) + L_dann(source + target)` with `lambda_dann` schedule (DANN paper: `lambda = 2 / (1 + exp(-10 * p)) - 1` where `p = epoch / total_epochs`).
- A CLI `scripts/train_dann_classifier.py` analogous to `scripts/train_lab_classifier.py` but accepting `--source-csv` (VocalMat) + `--target-csv` (`domain_unlabeled.csv`) instead of three splits.

A new test file `tests/classifier/test_dann.py` with the test-architect spec.

The 18.3 source files (`scripts/train_lab_classifier.py`, `src/usv_spectrogram/classifier/{model,augmentation,losses,training}.py`) should NOT be modified — DANN is additive, not a rewrite. The 18.3 classifier remains the non-DANN baseline.

## SHIP gates (Module 18.4)

(Subject to confirmation in `ROADMAP_lab_cnn_classifier.md` §18.4; the canonical list lives there.)

- [ ] DANN training converges (combined loss decreases monotonically once `lambda` ramps in; domain accuracy approaches 50% by end of training = features are domain-invariant).
- [ ] Macro F1 on VocalMat test split ≥ **0.65** (must not regress from 18.3's 0.7669; small regression acceptable if held-out lab improves substantially).
- [ ] Held-out lab USV/noise accuracy ≥ **0.80** (requires Tier-2 prep above).
- [ ] Confusion matrix on lab held-out: no class collapse > 0.40 mass (USV vs noise; the Grimsley breakdown is not applicable to lab — see 18.3 closeout §"Corrections").
- [ ] `models/lab_dann_classifier_v1/best.pt` saved.
- [ ] `results/lab_dann_classifier_v1/eval_report.md` with VocalMat metrics + lab USV/noise verdict metrics + DANN λ schedule + domain classifier accuracy curve.

If DANN does NOT beat the 18.3 baseline on the held-out lab eval, that's a real result — it means the cage-invariance hypothesis didn't pan out and the next step is either (a) different domain-adaptation architecture (CDAN, DSAN), or (b) accept that we need labeled lab data.
