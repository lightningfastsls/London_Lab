## Analysis (Pseudo-Spec for the Download Script)

New file: `scripts/cnn_download_vocalmat_sample.py`. Follow the Script CLI Pattern from `docs/architecture/patterns.md §4`. Skeleton:

```python
# CLI
# python scripts/cnn_download_vocalmat_sample.py \
#     --osf-project bk2uj \
#     --output-dir data/vocalmat_sample/ \
#     --n-per-class 200 \
#     [--dry-run]
#     [--full]   # bridges to 18.2b's full pull

# Use osfclient (`pip install osfclient`) or fall back to requests + the OSF
# REST API. Either way:
# 1. Read the OSF project manifest to enumerate files by class folder.
# 2. For each class, sample n_per_class filenames (stable seed=1729).
# 3. Download to data/vocalmat_sample/<class>/.
# 4. Build manifest CSV.
# 5. Skip already-downloaded files (idempotent).
# 6. Print final counts per class for the user to verify balance.
```

After download, run the gate:

```bash
.venv/bin/python scripts/cnn_cleaning_validation.py \
    --vocalmat-sample data/vocalmat_sample/ \
    --lab-131204-sample USV_lab_131204/<one_wav>.wav \
    --wild-5970-sample '5970 USV/<one_wav>.wav' \
    --sample-size 200 \
    --output-dir results/cleaning_validation/ \
    --report docs/handoffs/cleaning-validation-report.md
```

## Decision Gate — What the 4 Criteria Mean

| All 4 pass? | Action |
|---|---|
| **YES** — gate passes | Write `cleaning-validation-report.md` with GO verdict. Module 18.2b unlocks. Proceed to Phase 1.1 (full data prep) in the following session. |
| **NO — 1 criterion fails** | Examine ablation matrix: which layer combination was needed? If `all_layers` passes 3/4, the failure is one specific cleaning layer not pulling its weight. Try the missing-component combinations. |
| **NO — 2+ criteria fail** | Cleaning stack architecture needs work. Likely additions: broadband whitening (suppresses cage-broad spectral signatures), per-band Z-score, or noise floor matching. STOP and discuss before iterating code. |
| **NO — >70% migration after all_layers** | Cleaning stack fundamentally insufficient — cage acoustics aren't dominated by spectral features the stack targets (likely reverb or temporal patterns). Phase 2 territory. |

## Decision Point Before Starting

The download itself is conceptually simple but can be done two ways:

1. **Use osfclient** (`pip install osfclient`) — Python client for OSF. Cleanest but adds a dependency.
2. **Use requests + OSF REST API directly** — no new dep but more code.

Recommendation: (1) — osfclient is well-maintained and OSF API is stable enough that the dependency cost is small. Add to `requirements.txt` if it exists, or document in module doc as a one-time install.
