## Population strata — read before any number below

Both 3452 and 5970 are **wild-mouse couples** (male + female pairs of
wild-caught animals; the male is the vocalizer). N = **1 couple** per
cohort, NOT N = 1 animal. Same species in both cohorts. This comparison
is therefore **wild-vs-wild between-cohort** variability — two different
wild-mouse pairs.

The actual research-goal axis is **wild-vs-lab-strain**, which is blocked
pending lab-strain data (see `docs/handoffs/HANDOFF_05_LAB_DATA_PIPELINE.md`).

**Implication for how to read everything below:** any divergence quantified
in this memo (JSD = 0.37 bits, χ² p = 2e-79, MI 0.197 vs 0.092 bits) is the
**noise floor** that a future wild-vs-lab signal must exceed to be
interpretable as a strain effect rather than between-couple variability
within the wild stratum. These numbers are baseline-estimation, not the
headline conclusion of the project.

## TL;DR

3452 (animal `usv_lmt_035`, wild) and 5970 (animal `usv_lmt_034`, wild) share
the same acoustic feature *geometry* but differ dramatically in their
*repertoire usage*. PCA structure, feature correlations, and the continuum
finding replicate cleanly. Type proportions do not — 3452 is
**Short-dominated** (42.9 %) where 5970 is **Flat-dominated** (32.0 %), with
a Jensen-Shannon divergence of 0.37 bits (χ² = 381.9, dof = 6, p ≈ 2e-79).

## 1. Type distribution — radically different

| Type             | 5970 n  | 5970 %  | 3452 n | 3452 %  | Δ (pp)   |
|------------------|--------:|--------:|-------:|--------:|---------:|
| Short            | 1,113   | 14.2 %  | 172    | 42.9 %  | **+28.7** |
| Up               | 268     |  3.4 %  | 53     | 13.2 %  | **+9.8**  |
| Complex          | 687     |  8.7 %  | 30     |  7.5 %  | −1.3     |
| Chevron          | 1,312   | 16.7 %  | 47     | 11.7 %  | −5.0     |
| Frequency_Jump   | 579     |  7.4 %  |  9     |  2.2 %  | −5.1     |
| Down             | 1,385   | 17.6 %  | 16     |  4.0 %  | **−13.6** |
| Flat             | 2,520   | 32.0 %  | 74     | 18.5 %  | **−13.6** |

- **χ² test of independence (2 × 7 contingency):** χ² = 381.90, dof = 6, p = 2.17e-79
- **Jensen-Shannon divergence:** 0.371 bits (JSD² = 0.138)

**Biggest shifts:** 3452 triples its Short share (+28.7 pp), nearly
quadruples its Up share (+9.8 pp), and halves its Flat and Down shares
(−13.6 pp each). **⚠ DECISION-NEEDED SIGNAL:** the handoff calls out
"radically different type distributions (e.g., one type missing entirely)"
as a signal to surface. Frequency_Jump is not missing but is severely
suppressed (2.2 %, n = 9). Down is down to 4.0 % (n = 16). Both edge
close to unreliable counts for cell-level stats.

## 2. Feature correlations — the strong ones replicate

| Correlation pair                 | 5970 r | 3452 r | Replicates? |
|----------------------------------|-------:|-------:|:-----------:|
| Mean power (dB) ↔ Tonality       | 0.94   | 0.917  | ✓ yes       |
| Bandwidth (kHz) ↔ Freq SD (kHz)  | 0.85   | 0.923  | ✓ yes       |
| Low freq (kHz) ↔ Bandwidth       | −0.73  |  —     | weaker in 3452 |
| High freq (kHz) ↔ Bandwidth      |  —     | 0.732  | new pair in 3452 |

The 5970 finding "mean_power ↔ tonality r = 0.94" **holds in 3452 (r = 0.917).** The
effective dimensionality is the same ~7–8 features either animal. The third
strong correlation differs in *direction* (high-freq vs low-freq anchor)
but both point to the same underlying structure: narrow calls cluster
together spectrally; wide calls spread further.

## 3. PCA — nearly identical variance capture, same axes, different rotation

| Quantity        | 5970              | 3452              | Qualitatively same? |
|-----------------|-------------------|-------------------|:-------------------:|
| PC1 variance    | 33.4 %            | 39.2 %            | similar             |
| PC2 variance    | 27.0 %            | 22.3 %            | similar             |
| PC1 + PC2       | 60.4 %            | 61.5 %            | ✓ essentially same  |
| PC1 dominant    | bandwidth / spread| bandwidth / spread| ✓ same axis         |
| PC2 dominant    | power / clarity   | duration / power  | shifted             |

PC1 in 3452 is 39.2 % (up from 5970's 33.4 %) because with 20× less data the
leading axis captures *more* of the total variance — fewer low-variance
directions survive. **Loadings tell the same story:** PC1 = spectral spread,
PC2 = duration/power. The qualitative interpretation does not change. The
handoff's decision-needed threshold ("PC1 < 20 % variance or new dominant
axis") is not triggered.

## 4. UMAP — continuum finding holds

A3 on 3452 produced `umap_by_type.png` and `umap_by_feature.png`. The
programmatic summary notes "color gradients rather than discrete patches"
as the continuum signature — consistent with what was found for 5970 and
with Goffinet et al. (2021). A visual recheck of the two PNGs is
recommended before formally declaring replication, but nothing in the
numerics contradicts continuum. **Decision-needed signal ("discrete
clusters in 3452 but continuum in 5970") is NOT triggered by the numeric
summary.**

## 5. Boundary cases — leakiness shifts from Chevron to Short

| Metric                               | 5970              | 3452              |
|--------------------------------------|-------------------|-------------------|
| Low-confidence call rate             | 14.4 % (1130/7864)| 10.0 % (40/401)   |
| Leakiest type (n, % of low-conf)     | Chevron (301, 27%)| Short (16, 40 %)  |
| Second leakiest                      | Frequency_Jump (295, 26%) | Chevron (12, 30 %) |
| Top two types' share of low-conf     | 53 %              | 70 %              |

In 5970, Chevron and Frequency_Jump were flagged as the arbitrary boundaries
(sinuosity = 1.8 and bandwidth = 55 kHz cutting through density peaks). In
3452, Short is the single biggest contributor to ambiguity. **This is
expected given the distribution shift:** Short is 43 % of the 3452 population,
so it produces more low-confidence calls in absolute terms even if the
*per-type* leakiness rate is lower. A per-type boundary rate (low-conf in
type X / total type X) would correct for this and is worth computing
before concluding that Short is *actually* a leakier category in 3452.

## 6. Within-type variability — rankings roughly agree, absolute scales don't

The A3 script reports CV (coefficient of variation) per type. The 5970
handoff cites Short as loosest (CV = 1.48); the 3452 summary reports
Chevron = 35.7, Short = 6.9, Flat = 3.3. The absolute numbers diverge
by an order of magnitude — likely because 3452 has types whose mean
for some feature (e.g., slope) passes through zero, blowing up |std/mean|.
**The CV ranking is not directly comparable across the two runs without
recomputing on aligned features.** What replicates qualitatively:
Up and Down are the tightest types in both animals; Short and Chevron
are among the loosest. **TODO:** harmonize CV computation across the two
analyses before citing the numbers.

## 7. Sequential structure — 2× stronger in 3452, but small-N caveat

| Quantity (Phase A2, 0.6 s bout threshold)           | 5970    | 3452    |
|----------------------------------------------------|--------:|--------:|
| Marginal entropy H(C)                               | 2.544 b | 2.361 b |
| Conditional entropy H(C\|C−1)                       | 2.450 b | 2.088 b |
| MI at lag 1 (within-bout, scattoni_7_bout_aware)    | 0.092 b | **0.197 b** |
| Within-bout pair count (n)                          | 6,350   | 268     |
| Number of bouts                                     | 1,238   | 73      |
| Median ICI gap (ms)                                 | 86.68   | 171.92  |

3452's MI is **2.14× higher** than 5970's. With n = 268 pairs, however,
MI estimates carry finite-sample bias (Miller 1955; Roulston 1999).
The lag-1 MI upper bound is log₂(7) − (entropy curve) — at n = 268 the
noise floor is ~0.05 bits even under independence. The effect size (0.10 b
above 5970's canonical value) is detectable but should be verified with a
shuffle null before citing as a biological difference. **TODO:** run
`information_theory.py` bootstrap on the 3452 within-bout sequences.

Median ICI gap in 3452 is **2× longer** (172 ms vs 87 ms), consistent with
the lower call density per file and the smaller number of bouts per call.
