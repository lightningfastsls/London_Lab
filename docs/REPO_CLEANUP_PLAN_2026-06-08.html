Safety critic: safe-with-fixes

**State of the repo.** This is a ~150 GB, 7.8 GB-git-history USV science repo that is fundamentally *sound at the core* but *cluttered at the edges*. The good news from the audits is consistent and verified: the `.gitignore` is sophisticated and already shields the dangerous classes (zero tracked `__pycache__`, `*.pyc`, `*.zip`, `.venv/`, Zone.Identifier); the production model `models/hard_neg_retrain/*` is intact; the test suite is large and the science-critical surface (corpus constants, detection, FP-filter, event features, labeling) is well-covered with 1,584 passing tests; and the raw recordings + tracked detection outputs are correctly preserved (the `!`-reinclude rules exist *because* of the documented 656-file loss incident). The repo is mostly *missing-commits and stray-clutter*, not garbage. **Cleanup strategy.** Approve safest-first. Tier 0 is pure cruft you can delete blind (note: the real Zone.Identifier count is **18,273**, not ~21 — almost all of them sit *inside* the irreplaceable `USV_9252/` and `5970/` raw-data dirs, so the delete must be scoped by name `find -name '*:Zone.Identifier' -delete`, never a recursive dir wipe). Tier 1 organizes the chaotic root (24 loose `.md`, 9 `classified_detections*.csv`, scattered PLAN/ROADMAP/HANDOFF docs) into `docs/` + creates `docs/archive/`, and hardens `.gitignore` against the one real future-bloat risk (the ~6.3 GB un-ignored `data/alpha3_*patches/`). Tier 2 is confirm-each consolidation: `git rm --cached` the embedded unrelated **parts-finder** project (111 tracked files) and 4 empty tracked root stubs (`lab`/`persist`/`quantity`/`search`), commit the 213 valuable untracked handoff/script/safety-hook artifacts by exact path, and triage 19 erroring tests. Tier 3 is additive handoff polish (successor README, INSTALL+RUN doc, packaging, tools index). Tier 4 lists only the irreplaceable-data candidates (chunked corpus, review cascades, git history) for explicit per-item sign-off — never auto-recommended for deletion.
