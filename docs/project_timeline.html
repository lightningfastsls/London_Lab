Key Technical Achievements

CNN Classifier Performance

F1 = 91.7% (89.7% precision, 93.8% recall) on USV detection. Binary classifier with ~101K params, 3 conv blocks.

Transformer Architecture

25.6M parameter GPT-style autoregressive model for next-spectrogram-column prediction. Pre-norm, 8 layers, 8 heads, d_model=512.

VQ-VAE Codebook

K=64 codebook with EMA updates, dead code reinitialization, L2 normalization. ~820K params. Discovers discrete "concepts" in transformer hidden states.

Detection Pipeline

93 USV detections exported across 5 recordings as Raven selection tables. Two-stage detection: energy threshold + CNN classification.

Desktop Application

Fully functional PyQt6 desktop app for interactive USV detection, spectrogram visualization, threshold adjustment, and progressive labeling.

Test Coverage

600+ tests across the entire pipeline. Recording-based train/val/test splits (ADR-004) prevent data leakage.
