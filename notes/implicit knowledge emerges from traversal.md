# implicit knowledge emerges from traversal

Traversal through a knowledge graph produces understanding beyond what any individual note states. As an agent follows links between notes, it accumulates context that enables pattern recognition — seeing connections that weren't explicitly documented. Since [[knowledge lives in paths between notes not in any single note]], the inter-note knowledge is generated fresh each traversal. Since [[spreading activation models how agents should traverse]], the activation pattern determines which implicit knowledge becomes visible.

The practical implication: a note read in isolation teaches one claim, but the same note encountered mid-traversal teaches that claim plus its relationship to everything the traverser has held in context. This is why traversal order matters, why topic maps shape understanding, and why the same vault can produce different insights depending on entry point and path taken.
