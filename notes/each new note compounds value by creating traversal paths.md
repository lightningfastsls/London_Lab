# each new note compounds value by creating traversal paths

Each note added to the vault creates new traversal paths proportional to its outgoing links. A note with 3 links creates 3 new paths, but also enables multi-hop paths through those connections. Since [[knowledge lives in paths between notes not in any single note]], each new path is a potential source of emergent inter-note knowledge. The compounding is not just about reachability — it is about generative capacity. More paths means more possible syntheses during traversal.

Since [[inline links carry richer relationship data than metadata fields]], well-typed links create higher-quality paths that generate richer knowledge. A note with three "since `[[...]]`" links produces paths with causal reasoning baked in, while a note with three bare `[[...]]` links produces paths that require the traverser to infer the relationship. The combinatorial growth in value is thus a function of both link count and link quality.
