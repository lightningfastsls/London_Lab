# agent-external-cognition

How the vault, hooks, and session design extend agent cognition beyond what the context window and model weights provide. Split from [[agent-cognition]] to separate "what goes wrong in sessions" ([[multi-turn-degradation]]) from "how external structures compensate." For graph structure theory, see [[graph-structure]]. For cross-session memory infrastructure, see [[agent-memory]].

## Synthesis

Agents are not just models — they are models embedded in cognitive scaffolding. Since [[external memory shapes cognition more than base model]], the vault's structure determines reasoning paths more than training weights. Since [[scaffolding enables divergence that fine-tuning cannot]], this scaffolding achieves per-instance behavioral divergence without touching the model. The system self-improves at two scales: since [[hook-driven learning loops create self-improving methodology through observation accumulation]], the macro loop operates between sessions via thresholds, while since [[traversal simultaneously improves the traverser and the graph creating a co-evolutionary loop]], the micro loop operates within sessions via incidental improvement during purposeful work.

## Hook Theory
Hooks model automatic procedural behavior — the cognitive equivalent of habits that fire without deliberation.
- [[hooks are the agent habit system that replaces the missing basal ganglia]] — hooks as automated procedural behavior, providing consistency that degrades under cognitive load
- [[session boundary hooks implement cognitive bookends for orientation and reflection]] — orient-work-persist rhythm enforced by session-start/end hooks
- [[schema validation hooks externalize inhibitory control that degrades under cognitive load]] — quality control as externalized cognition under task pressure
- [[hook-driven learning loops create self-improving methodology through observation accumulation]] — macro-level self-improvement: observations accumulate, thresholds fire, patterns emerge
- [[nudge theory explains graduated hook enforcement as choice architecture for agents]] — Thaler's nudge theory: warn before block, preserve autonomy, escalate on repeated violations
- [[automation should be retired when its false positive rate exceeds its true positive rate or it catches zero issues]] — hygiene principle: noisy automation trains agents to ignore all gates

## Traversal & Emergent Knowledge
Knowledge is generated by traversal, not just retrieved — the graph is productive, not merely navigable.
- [[knowledge lives in paths between notes not in any single note]] — ontological claim: the vault is a generator of inter-note knowledge visible only during traversal
- [[different traversal starting points produce different emergent knowledge from the same graph]] — path-dependence: entry point determines which patterns become visible
- [[traversal simultaneously improves the traverser and the graph creating a co-evolutionary loop]] — bidirectional improvement: each traversal both extracts and deposits value
- [[implicit knowledge emerges from traversal]] — traversal builds intuition beyond what any single note contains
- [[spreading activation models how agents should traverse]] — cognitive science model: activating one node primes connected nodes during vault traversal
- [[the vault constitutes identity for agents]] — for agents without persistent memory, the vault IS the cognitive substrate

## Between-Session Processing
The gaps between sessions are not dead time — they are productive consolidation periods.

- [[session boundaries simultaneously limit agents and enable between-session processing making the limitation the precondition]] — the paradox: continuity destruction enables consolidation
