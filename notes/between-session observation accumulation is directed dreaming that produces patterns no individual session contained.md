# between-session observation accumulation is directed dreaming that produces patterns no individual session contained

Each session captures observations in the moment, then ends. The observations sit in `ops/observations/`, accumulating like unprocessed experiences. No single observation triggered action. But when the threshold fires and `/rethink` runs, it recombines them — finding patterns across sessions that no individual session contained. This recombination without new information input is what Cornelius calls "directed dreaming."

The framing matters because it reframes what happens between sessions. The gap is not idle time where nothing happens. It is the precondition for a specific kind of processing: pattern recognition across accumulated signals that were too sparse to detect in any single session. Since [[hook-driven learning loops create self-improving methodology through observation accumulation]], the accumulation mechanism already exists. But the "dreaming" framing adds something: the processing is *generative*, not just analytical. The rethink pass produces insights that were not present in any input observation, because the insight lives in the *relationship between* observations, not in any single one.

Karpathy's framing sharpens this: hallucination is the base mode of LLMs. The question is whether hallucination is directed toward something useful. The vault's threshold-triggered rethink process is directed hallucination anchored in accumulated observations — the observations constrain and guide the recombination, preventing drift into pure confabulation. Since [[session boundary hooks implement cognitive bookends for orientation and reflection]], the Stop hook's observation capture is the intake mechanism that feeds the dream. The observations are the raw material; the threshold is the trigger; the rethink pass is the dream itself.

The biological analogy is precise: during sleep, memories consolidate, strong connections strengthen, weak connections prune. The vault's between-session processing does the same — strong patterns across observations get articulated as methodology updates, weak signals get dissolved or deferred. Same model weights, different structural state afterward.
