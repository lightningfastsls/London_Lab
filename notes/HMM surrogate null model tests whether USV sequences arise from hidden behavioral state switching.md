# HMM surrogate null model tests whether USV sequences arise from hidden behavioral state switching

The HMM surrogate null model occupies a critical position in the null model hierarchy because it directly tests a biologically motivated hypothesis: that USV code sequences are generated by switching between a small number of hidden behavioral states, each with its own emission distribution over codes. The procedure uses Baum-Welch expectation-maximization to fit an HMM with n_states hidden states and K emission symbols to the observed code sequences, then generates surrogate sequences by sampling from the fitted model. If real data metrics are statistically indistinguishable from HMM surrogates, the "hidden behavioral states" hypothesis is sufficient to explain all observed sequential structure.

This null model is particularly relevant because it directly tests the framework proposed by Chabout et al. (2015), who showed that male mice change syllable syntax depending on social context — which implies that behavioral state (alone with female, in presence of urine, with anesthetized female) modulates the statistical properties of vocalization sequences. An HMM formalizes this intuition: hidden states correspond to behavioral modes, and transitions between states generate the observed temporal structure. Therefore, if real data matches HMM surrogates, the structure is fully explained by state switching with memoryless emissions within each state.

But if real data significantly exceeds HMM surrogates on metrics like excess entropy or n-gram idiom frequencies, this implies structure beyond what state switching can capture. This would be evidence for within-state sequential dependencies — something closer to grammatical rules operating within behavioral modes, not just switching between modes. This distinction matters because it separates two very different kinds of "syntax": state-dependent emission probabilities (which any animal with behavioral modes would exhibit) versus genuine compositional structure within a behavioral state (which would be much more language-like).

The choice of n_states requires model selection. BIC or cross-validated log-likelihood over a range (e.g., n_states = 2 to 10) identifies the optimal number of hidden states. Using too few states makes the null model too weak (easy to exceed), while too many states makes it too flexible (hard to exceed), which means careful model selection is essential for interpretable results.
