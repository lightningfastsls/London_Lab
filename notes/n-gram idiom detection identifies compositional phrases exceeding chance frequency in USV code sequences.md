# n-gram idiom detection identifies compositional phrases exceeding chance frequency in USV code sequences

Simply counting frequent n-grams — as the existing `top_ngrams()` function in `sequence_analysis.py` does — conflates high frequency with statistical significance. A bigram composed of two common codes will appear often purely by chance, because the expected count of bigram (a, b) under independence is N * p(a) * p(b), where p(a) and p(b) are the unigram probabilities. A bigram that appears 500 times may seem frequent, but if both constituent codes have probability 0.1 and the dataset has 50K tokens, the expected count under independence is already 500. That bigram is not over-represented — it is exactly at chance level.

Idiom detection addresses this by comparing observed n-gram counts against a null distribution generated by shuffling the sequence (preserving unigram frequencies but destroying all temporal order). For each n-gram, the procedure computes how many times it appears in the real data versus in many shuffled surrogates, yielding a z-score that measures how many standard deviations above the null expectation the observed count falls. Because thousands of n-grams are tested simultaneously, Benjamini-Hochberg FDR correction controls the false discovery rate, ensuring that the identified "idioms" are not simply the expected tail of a large multiple-comparison exercise.

N-grams surviving this filter — with z-score greater than 3 or FDR-corrected p-value below 0.01 — are candidates for compositional "phrases": recurring multi-code patterns that the VQ-VAE system produces more often than code frequencies alone would predict. These are the discrete analogs of fixed expressions or collocations in natural language, and their existence (or absence) directly tests whether USV code sequences have compositional structure beyond what marginal frequencies explain. This connects to [[bigram productivity ratio measures compositionality of USV code sequences]], which measures the breadth of combination (how many unique pairs occur) while idiom detection measures the depth (which specific combinations are over-represented). Together, they provide a complete picture of pairwise compositional structure.
