# event-triggered USV rate via PETH in plus-minus 2 second windows per event type serves as LMT integration sanity check

The peri-event time histogram (PETH) is a standard neuroscience method adapted here for USV-behavior correlation analysis. For each behavioral event type tracked by the Live Mouse Tracker — approach, contact, oral-oral, oral-genital, side-by-side, follow — the method computes the USV emission rate in a window of plus or minus 2 seconds centered on the event onset. The window is divided into bins of approximately 100 ms, and the number of USV onsets falling within each bin is counted across all instances of that event type, then normalized by the number of events and bin width to yield a rate in USVs per second.

This is Tier 1 analysis — the simplest and most important cross-modal result — because it answers the most basic question: do USVs correlate with social behavior at all? If the PETH shows no modulation of USV rate around any behavioral event, something fundamental is wrong, either with the temporal alignment between USV detections and LMT behavioral annotations, or with the assumption that vocalizations are socially relevant in this context. Therefore, this analysis serves as a sanity check that must pass before any more sophisticated cross-modal analysis proceeds.

The baseline comparison is the whole-recording average USV rate, tested via permutation. The observed peri-event rate is compared against a null distribution generated by circularly shifting USV onset times relative to behavioral event times (typically 1000 permutations), which preserves the temporal autocorrelation structure of both streams while destroying their cross-correlation. If the observed peri-event rate exceeds the 95th percentile of the permutation distribution for a given event type and time bin, the USV-behavior coupling is statistically significant.

Beyond the sanity check function, PETHs can reveal biologically meaningful timing patterns. If USV rate peaks 500 ms before oral-oral contact, vocalizations may serve an anticipatory or solicitation function. If the rate peaks after contact onset, they may be a response or accompaniment. But the most scientifically interesting comparison is between wild and lab mouse populations: if wild mice show stronger event-USV coupling than lab mice — sharper PETH peaks with higher peak-to-baseline ratios — that constitutes evidence for courtship degradation even before any sophisticated information-theoretic analysis, because it means wild mice vocalize more specifically in relation to social events while lab mice vocalize more diffusely.
