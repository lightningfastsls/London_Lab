# hook-driven learning loops create self-improving methodology through observation accumulation

Individual observations about methodology friction — a skill that misfires, a schema field that confuses, a traversal pattern that fails — are individually insignificant. But since [[between-session observation accumulation is directed dreaming that produces patterns no individual session contained]], when enough observations accumulate (threshold: 7), the /rethink process fires and patterns emerge through generative recombination.

Hooks automate the capture: when an agent encounters friction, a hook logs it to ops/observations/ without interrupting the primary task. The learning loop is: friction → automatic capture → accumulation → threshold → pattern recognition → methodology update. Since [[traversal simultaneously improves the traverser and the graph creating a co-evolutionary loop]], this is the macro-level complement to micro-level co-evolutionary improvement. The micro level improves individual notes during traversal; the macro level improves the methodology itself through accumulated observations about what works and what doesn't.
