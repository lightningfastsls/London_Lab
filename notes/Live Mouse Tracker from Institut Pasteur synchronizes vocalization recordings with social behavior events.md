# Live Mouse Tracker from Institut Pasteur synchronizes vocalization recordings with social behavior events

The Live Mouse Tracker (LMT) from Institut Pasteur (https://micecraft.org/lmt/) is the behavioral tracking system used in this research. LMT tracks mouse social behavior (approaches, contacts, follows, etc.) and synchronizes these events with USV recordings captured by [[AviSoft Recorder captures synchronized USV recordings within the LMT behavioral tracking system]]. This temporal synchronization is foundational for the core research question: since [[wild versus lab mouse USV comparison tests whether domestication altered vocal repertoires]], having behavioral context for each USV enables analysis of whether call types correlate with specific social situations. An LMT USV Toolbox (Python) is also available for offline processing, and a cloud testing platform exists at usv.pasteur.cloud.
