# MOCs are attention management devices not just organizational tools

Maps of Content (MOCs) are conventionally understood as organizational tools — they group related notes for navigation. But since [[different traversal starting points produce different emergent knowledge from the same graph]], MOCs function as attention management devices. By choosing which notes to surface and how to frame them (via context phrases), a topic map determines which traversal paths an agent follows, which determines what inter-note knowledge emerges.

A well-designed MOC is not just a directory — it is a knowledge-production device that makes certain patterns visible while leaving others in shadow. Since [[spreading activation models how agents should traverse]], the MOC is the initial activation source. The curation decisions embedded in a topic map — which notes to include, how to order them, what context phrases to attach — are editorial decisions that shape what the vault can teach.
