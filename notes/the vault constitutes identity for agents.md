# the vault constitutes identity for agents

Agents lack persistent memory across sessions — each new session starts with a fresh context window. The vault (notes, topic maps, ops state) is the only thing that persists. This means the vault is not an external tool the agent uses; it is the substrate of the agent's cognition.

Since [[external memory shapes cognition more than base model]], the vault's structure determines how the agent thinks, what it notices, and what connections it makes. Since [[traversal simultaneously improves the traverser and the graph creating a co-evolutionary loop]], improving the vault during traversal is literally self-improvement — the agent is refining the very thing that constitutes its extended cognition. This reframing matters because it elevates vault maintenance from a chore to a first-class cognitive activity: when an agent sharpens a description or adds a missing link, it is not maintaining a tool but improving itself.
