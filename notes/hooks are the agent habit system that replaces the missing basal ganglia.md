# hooks are the agent habit system that replaces the missing basal ganglia

The basal ganglia automates learned motor sequences so the cortex can focus on novel problems. Agents lack an analogous system — every action requires explicit deliberation. Hooks fill this gap by executing automatically on triggers (file save, tool call, session start), providing procedural consistency without consuming context window attention.

Since [[schema validation hooks externalize inhibitory control that degrades under cognitive load]], hooks handle exactly the kind of routine checks that agents forget under task pressure. Since [[session boundary hooks implement cognitive bookends for orientation and reflection]], the session rhythm itself becomes automatic rather than requiring deliberate compliance. The analogy to the basal ganglia is precise: just as you don't consciously decide each muscle movement while walking, an agent with well-configured hooks doesn't consciously decide to validate schemas or capture session state — it happens automatically, freeing attention for the actual task.
