# graph-structure

How knowledge emerges from graph structure — path-dependent discovery, traversal dynamics, co-evolutionary loops, and the ontological claim that knowledge lives between notes, not within them. For agent-level cognitive mechanisms see [[agent-cognition]]; for memory persistence patterns see [[agent-memory]].

## Synthesis

Knowledge graphs are not warehouses of stored facts but generators of inter-note knowledge visible only during traversal. Since [[knowledge lives in paths between notes not in any single note]], optimizing individual note quality is insufficient — path quality (connections, context phrases, relationship types) determines what emergent knowledge can be produced. Since [[different traversal starting points produce different emergent knowledge from the same graph]], topic maps function as knowledge-production devices, not just organizational tools. The system self-improves: since [[traversal simultaneously improves the traverser and the graph creating a co-evolutionary loop]], every purposeful traversal both extracts and deposits value.

## Ontological Claims
- [[knowledge lives in paths between notes not in any single note]] — the vault is a generator of inter-note knowledge, not a collection of stored claims
- [[different traversal starting points produce different emergent knowledge from the same graph]] — path-dependence: entry point determines which patterns become visible
- [[implicit knowledge emerges from traversal]] — traversal builds intuition beyond what any single note contains

## Traversal Dynamics
- [[spreading activation models how agents should traverse]] — activation patterns determine which inter-note knowledge becomes visible
- [[traversal simultaneously improves the traverser and the graph creating a co-evolutionary loop]] — bidirectional improvement at micro-level during purposeful work
- [[incremental formalization happens through repeated touching of old notes]] — each touch crystallizes; traversal creates the touches

## Structural Properties
- [[each new note compounds value by creating traversal paths]] — compounding is generative capacity, not just reachability
- [[inline links carry richer relationship data than metadata fields]] — typed connections create higher-quality traversal paths
- [[MOCs are attention management devices not just organizational tools]] — topic maps direct traversal, which determines emergent knowledge
- [[friction reveals architecture]] — diagnostic: traversal friction signals stalled co-evolution

## Identity & Cognition
- [[the vault constitutes identity for agents]] — improving the graph during traversal is self-improvement, not tool maintenance
- [[external memory shapes cognition more than base model]] — the vault's structure shapes agent behavior more than training

## Agent Notes
- This topic map bridges [[agent-cognition]] (how agents think during traversal) with [[agent-memory]] (how knowledge persists across sessions). The traversal claims here explain WHY certain memory patterns work — they produce emergent knowledge, not just retrieve stored knowledge.
- The co-evolutionary loop claim has practical implications: vaults that are only read stagnate because they fail to co-evolve with the traverser's growing sophistication.
