# Combined cross-modal evidence from USV repertoire and MiceCraft movement data builds a stronger case for courtship degradation

The significance criterion for the courtship degradation hypothesis is explicitly cross-modal: the case is strongest when both USV repertoire analysis AND video-based movement analysis (via MiceCraft) converge on the same conclusion. MiceCraft detects known movement behaviors from video (approaches, follows, contacts, mounting), while USV analysis captures the vocal component. If both show that wild mice have richer, more complex courtship behavior than lab mice, the combined evidence is more compelling than either alone. This cross-modal strategy connects since [[USVs are one component of a multimodal courtship behavior suite including mounting approach and movement]] — the courtship display spans multiple channels, so the degradation analysis should span them too.
