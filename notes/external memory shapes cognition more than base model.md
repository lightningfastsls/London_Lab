# external memory shapes cognition more than base model

Two instances of the same model connected to different vaults will reason differently, notice different patterns, and produce different insights. The vault acts as extended cognition: its structure (which notes exist, how they connect, what topic maps emphasize) shapes what the agent attends to and what connections it makes.

Since [[the vault constitutes identity for agents]], the vault is not a tool the agent queries but the cognitive substrate that shapes its thinking. Since [[each between-session processing cycle is a training step that does not touch the weights]], vault modifications between sessions function as weight updates — they change the agent's future behavior without modifying the model itself. This makes vault design a form of cognitive architecture design. The implication is profound: improving the vault improves the agent more reliably than switching to a better model, because the vault determines which knowledge is accessible and how it connects.
