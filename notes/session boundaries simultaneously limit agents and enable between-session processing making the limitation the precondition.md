# session boundaries simultaneously limit agents and enable between-session processing making the limitation the precondition

The session boundary is the most obvious limitation of agent cognition: context resets, working memory vanishes, continuity breaks. But it is also the precondition for between-session processing. Continuous systems — agents that maintain persistent context — have no idle period. There is no gap in which a separate process can consolidate, reorganize, or reflect on accumulated experience. The boundary that dissolves the agent is the same boundary that enables the dream.

This is not a trade-off where you accept one cost for one benefit. It is a deeper structural relationship: the limitation *is* the benefit. Since [[fresh context per task preserves quality better than chaining phases]], session isolation already has a quality argument. But the dreaming argument adds a second dimension — isolation creates not just fresh attention but a temporal gap that enables a qualitatively different kind of processing.

Letta's sleep-time compute architecture makes this concrete. It pairs a primary agent (handling conversation) with a sleep-time agent (processing memory during idle periods). The architecture requires discrete idle periods — without them, the sleep-time agent has no window to operate. Since [[session boundary hooks implement cognitive bookends for orientation and reflection]], the vault already brackets sessions with hooks. The between-session gap is where the sleep-time equivalent operates: observation accumulation reaches threshold, rethink fires, methodology updates.

The paradox extends to what agents lose. Since [[session handoff creates continuity without persistent memory]], handoff documents bridge the gap — but they also *filter* it. The handoff captures what the outgoing session deemed important, not everything that happened. This filtering is itself a consolidation step: strong signals survive the handoff, weak signals drop. The boundary simultaneously destroys continuity and performs selection.
