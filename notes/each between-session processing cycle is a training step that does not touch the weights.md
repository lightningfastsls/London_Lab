# each between-session processing cycle is a training step that does not touch the weights

What the industry calls fine-tuning — adapting a model's behavior through gradient updates — the vault achieves through structure. Each cycle of between-session processing follows the same functional pattern as a training step: capture signal (observations), accumulate over episodes (threshold counting), process batch (rethink), update parameters (methodology revision). The difference is that the "parameters" being updated are vault structure — topic maps, methodology notes, CLAUDE.md rules, hook configurations — not model weights.

Since [[scaffolding enables divergence that fine-tuning cannot]], the vault's structural adaptation has an advantage fine-tuning lacks: it is instance-specific and immediately effective. A weight update requires retraining and applies globally. A vault update takes effect at the next session start and applies only to this agent's context. Since [[external memory shapes cognition more than base model]], what gets retrieved determines what gets thought — so updating the vault changes cognition as effectively as updating weights, but faster and more precisely.

The "training step" framing is not just metaphorical. The functional components align: the Stop hook captures gradients (observations about what worked and what didn't). The threshold trigger determines batch size (how many observations accumulate before processing). The rethink pass performs the update (consolidating observations into methodology changes). The next session's Start hook loads the updated parameters (revised orientation, new health thresholds, updated methodology notes). Since [[between-session observation accumulation is directed dreaming that produces patterns no individual session contained]], the processing step is generative — it produces insights not present in any individual observation, just as gradient aggregation across a batch produces updates not present in any individual example.

The implication is that agent improvement is possible without any access to model weights. Same base model, iterated structural improvement, progressively better agent. The vault IS the differentiation layer.
