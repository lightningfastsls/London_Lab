# schema validation hooks externalize inhibitory control that degrades under cognitive load

Inhibitory control — the ability to suppress incorrect responses and maintain quality standards — is one of the first cognitive functions to degrade under load. For agents, this manifests as skipping validation steps when focused on complex tasks: missing required fields, forgetting topic assignments, writing vague descriptions.

Schema validation hooks externalize this inhibitory control by checking note quality automatically before commits. Since [[hooks are the agent habit system that replaces the missing basal ganglia]], the hook provides consistent quality gating without consuming attention. Since [[nudge theory explains graduated hook enforcement as choice architecture for agents]], the hook can warn rather than block, preserving agent autonomy while preventing the worst failures. The key insight is that the quality standard doesn't degrade just because the agent is busy — the hook maintains it independently of the agent's cognitive state.
