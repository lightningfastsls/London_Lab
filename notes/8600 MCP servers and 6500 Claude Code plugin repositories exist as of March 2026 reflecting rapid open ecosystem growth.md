# 8600 MCP servers and 6500 Claude Code plugin repositories exist as of March 2026 reflecting rapid open ecosystem growth

The MCP ecosystem as of March 2026: 8,600+ registered MCP servers (PulseMCP directory), 6,500+ Claude Code plugin repositories indexed by the community, 55+ official Anthropic-verified plugins. MCP has been adopted as an industry-wide standard by Anthropic, OpenAI (ChatGPT, March 2025), Google (Gemini, April 2025), and Microsoft.

The official MCP Registry at `registry.modelcontextprotocol.io` is metadata-only (no code/binaries), intentionally minimal, and community-owned backed by Anthropic, GitHub, PulseMCP, and Microsoft. Preview since September 2025, progressing toward GA. Organizations can create sub-registries.

This growth rate — from a handful of reference servers to 8,600+ in approximately one year — validates the MCP design philosophy of minimal friction. The shift from passive context-stuffing (loading documentation into context) to active tool-calling (invoking tools via MCP) is the defining architectural change of 2025-2026.

For this vault's infrastructure planning, the ecosystem size means that MCP servers exist for nearly any capability needed. Since [[96 MCP memory servers exist as of March 2026 fragmented across unstructured markdown knowledge graph and hybrid vector-graph paradigms]], memory alone accounts for about 1% of the total MCP ecosystem — the remaining 99% covers code search, database access, browser automation, documentation, and more.
