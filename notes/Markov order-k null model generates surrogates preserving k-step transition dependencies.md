# Markov order-k null model generates surrogates preserving k-step transition dependencies

The Markov order-k null model is the second level in the null model hierarchy, testing whether observed sequential structure exceeds what k-step local dependencies can explain. The procedure fits a k-th order Markov chain to the observed data by estimating transition probabilities P(C_t | C_{t-1}, ..., C_{t-k}) from empirical k+1-gram counts. New surrogate sequences are then generated by sampling from this fitted model, which means the surrogates exactly preserve k-gram transition statistics but destroy any structure that depends on memory longer than k steps.

This null model is more conservative than shuffling, because it preserves genuine local temporal structure. A first-order Markov model (k=1) preserves bigram transition probabilities, which means if code A frequently follows code B in the real data, it will do so at the same rate in surrogates. Therefore, any metric that exceeds the Markov-1 null reflects structure beyond pairwise transitions — something that cannot be explained by "the next code depends only on the current code."

Testing k=1, 2, and 3 systematically reveals the effective memory depth of USV code sequences. If real data metrics match the Markov-1 null, then first-order dependencies fully explain the observed patterns. If real data exceeds Markov-1 but matches Markov-2, the structure has exactly two-step memory. If real data exceeds even Markov-3, the sequences contain long-range dependencies that local context cannot capture — which would be strong evidence for hierarchical or compositional structure in USV sequences.

There is a practical limitation: as k increases, the number of possible k-grams grows as K^k (where K is the codebook size), which means higher-order Markov models become data-hungry. With K=64 codes and k=3, there are 64^3 = 262,144 possible trigram contexts, many of which will have zero or very few observations. Laplace smoothing or Kneser-Ney smoothing mitigates this sparsity but introduces its own assumptions. Therefore, Markov null models are most reliable for low orders (k=1 to 3), and the [[entropy rate decreasing with context length indicates sequential predictability in USV code streams]] analysis complements them by measuring conditional entropy at higher orders without generating surrogates.
