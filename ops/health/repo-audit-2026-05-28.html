5 · AI-literacy profile & prompt cheat-sheet

Level: advanced operator — strong on session/agent orchestration and empirical grounding; the gap is pre-emptive constraint specification. (Corpus: 254 genuine human prompts across 42 sessions.)

What you already do well — keep doing

  • Context as a finite budget — proactive handoffs ("give me a handoff for a new chat" ×12) before context rot.
  • Agents as dispatchable workers — "orchestrate / spawn / launch an agent" ×8.
  • Adversarial verification — "spawn a chat that would be adversarial... really try to grill" (the most sophisticated single prompt in the corpus).
  • Empirical discipline — insists on the right eval (whole-file ROC over curated plateau), dense Y/N/U hand-labels, rejects suspicious numbers ("No way FP filter drops that many USVs you are doing something wrong").

The 3 gaps that would most improve results

  • Front-load constraints instead of correcting after. You react well but rarely fence up front. Highest ROI — converts ~1 rework round-trip per ambiguous task into zero.
  • Name the referent on first mention in a repo with 3 "cleaning pipelines", 2 deprecated CNN models, 2 duration columns.
  • Ask for verifiable form — tables, file:line citations, regression guards — turning your manual after-the-fact verification into something the agent produces checkably.
